# Agent and prompt evaluation

- Keep observed human feedback separate from model-generated observations; review both against actual evidence. Start from real failures or representative tasks, with reviewed expected behavior and concrete observable criteria. Preserve independent holdout cases for generalization. Use a mix of normal, hard and failure cases; avoid scoring mere presence of preferred phrases.
- For attribution, change one intended variable (skill, instruction, model, harness, etc.) at a time unless deliberately testing a combined intervention. Match model, reasoning budget, tools, permissions, data and task inputs for baseline and candidate. Use fresh isolated sessions and working directories; record versions and cost/latency. Repeat or counterbalance when stochastic variation matters.
- Give candidates natural user tasks without evaluator hints, rubric, labels or another candidate's outputs. Make environment names neutral without hiding actual product context. Do not expose private transcripts to unauthorized vendors or services.
- Evaluate mechanical claims using executable assertions or actual resulting state. For recorded outputs with stable mechanical assertions, use the optional deterministic replay helper in `references/replay.md`; it does not execute agents or judge semantic quality. For semantic judgments, use the same predefined rubric with anonymized and order-balanced outputs; use independent judgment and inspect disputed findings. A valid quotation alone does not establish that it supports a claim.
- Compare paired results per case and criterion, including regressions and false stops, rather than hiding them in a single average. Check actual tool calls, code and artifacts where authorized instead of taking compliance claims on faith. Judge disagreements and small samples limit confidence.
- Promote a change only when evidence supports its intended effect without unacceptable regressions or cost; otherwise reject, narrow or keep it provisional. Static validation only proves structural contracts. Record the evidence and verification gaps in the PR or task report, not a permanent ledger of private outputs.
